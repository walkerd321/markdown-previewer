# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub Security Advisories for this repository. Include affected versions, reproduction steps, and impact. Do not publish a proof-of-principle before a fix is available.

## Supported versions

The latest tagged GitHub Pages deployment is supported. Older tags are not independently maintained.

## Data handling

Markdown Previewer runs entirely in the browser. Drafts are stored in browser local storage; the application does not send draft content to a server. Rendered HTML is sanitized before display and export.
